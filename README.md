 # Retail Chain Profit Leakage & Demand Optimization

## 📌 Project Overview

This project analyzes retail sales, inventory, returns, vendor supply, promotions and customer data to identify profit leakage and demand optimization opportunities.

The objective is to understand why strong sales do not always result in strong profitability and to provide data-driven insights for better business decisions.

## 🛠️ Tools & Technologies

- Python
- Jupyter Notebook
- SQL Server
- Microsoft Excel
- Power BI
- Tableau

## 📊 Data Analysis

The project involved:

- Data cleaning and validation
- Missing-value analysis
- Duplicate detection
- Outlier analysis
- Sales and profitability analysis
- Return-loss analysis
- Inventory and stockout analysis
- Discount and promotion analysis
- Vendor performance analysis
- KPI development
- Business dashboard development

## 🔍 Key Findings

- Analyzed **80,224 cleaned sales transactions**.
- Identified approximately **₹1.64 million in return-related loss**.
- Identified recurring stockout situations representing potential lost-sales opportunities.
- Found that strong sales do not necessarily result in strong profitability.
- Evaluated discounts and promotions based on profitability rather than sales volume alone.

## 📈 Business Questions

The analysis focused on questions such as:

1. Which products generate high sales but low profitability?
2. How much profit is lost through product returns?
3. Which products experience recurring stockouts?
4. How do discounts affect profitability?
5. Which promotions contribute to profitable sales?
6. Which products and categories require business attention?
